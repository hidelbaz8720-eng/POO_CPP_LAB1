# TP 1 : Définition des classes en C++

##  Description
Ce projet a été réalisé dans le cadre du cours **Programmation orientée objet en C++** sur la plateforme MLIAEdu. Il permet de pratiquer les bases de la programmation orientée objet à travers deux exercices.

##  Objectifs
- Comprendre la création et l'utilisation des classes en C++.
- Utiliser les attributs privés et les méthodes publiques.
- Implémenter des constructeurs et des méthodes membres.
- Organiser le code dans plusieurs fichiers.
- Appliquer les principes d'encapsulation et de const-correctness.

##  Exercice 1 : BankAccount
Création d'une classe pour gérer un compte bancaire avec les fonctionnalités suivantes :
- Déposer de l'argent.
- Retirer de l'argent.
- Afficher les informations du compte.

##  Exercice 2 : Book et Library
Création d'un petit catalogue de livres permettant de :
- Ajouter un livre au catalogue.
- Rechercher un livre par son ISBN.
- Afficher la liste des livres.
- Éviter les doublons grâce à la vérification de l'ISBN.

##  Technologies utilisées
- **Langage :** C++
- **Concepts :** Programmation orientée objet (POO)
- **Bibliothèques :** `iostream`, `string`, `vector`

## 📂 Organisation des fichiers

- `BankAccount.hpp` : déclaration de la classe BankAccount.
- `BankAccount.cpp` : implémentation des méthodes du compte bancaire.
- `Book.hpp` : déclaration de la classe Book.
- `Book.cpp` : implémentation des méthodes de la classe Book.
- `Library.hpp` : déclaration de la classe Library.
- `Library.cpp` : implémentation des méthodes de la classe Library.
- `main.cpp` : programme principal pour tester les fonctionnalités.

Conclusion
Ce TP m'a permis de mieux comprendre les classes, les objets et l'encapsulation en C++. Il m'a également aidé à organiser un projet en plusieurs fichiers et à mettre en pratique les bases de la programmation orientée objet.
